**Graceful degradation** means an app still works but it might affect by some outer issue and shows fewer features. **Service workers** means caching files and data in the browser. When the user has a good internet connection, the app fetches everything from the network, but when the connection is slow/offline, the service worker serves the cached versions instead of showing an error. Based on this, the app doesn't break, it will falls back to what it already saved.
